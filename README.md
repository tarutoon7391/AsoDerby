# ブロック馬 競馬シミュレーション オンライン版

`public/index.html` がゲーム本体、`server.js` がランキングと対戦のサーバーです。

## ローカルで動かす

```powershell
npm install
npm start
```

ブラウザで http://localhost:3000 を開く。

## Railway にデプロイ

1. このフォルダを GitHub の新しいリポジトリ（main ブランチ）に push
2. Railway で「New Project → Deploy from GitHub repo」でそのリポジトリを選ぶ
3. 自動で `npm install` → `npm start` が走る。Settings → Networking で「Generate Domain」すれば URL が出る

### データを消えないようにする（ほぼ必須）

アカウント・牧場のセーブデータ・ランキングはすべて `data/db.json` に保存されます。
Railway はデプロイのたびにファイルが消えるので、Volume を追加して、環境変数 `DATA_DIR` にそのマウント先（例 `/data`）を設定してください。
これをしないと、再デプロイのたびに全員のアカウントとデータが消えます。

## アカウント

- 開くとログイン画面が出る。ユーザーID（半角英数字3〜16文字）・プレイヤー名・パスワード（4文字以上）で新規登録
- ログインすると牧場のデータがサーバーに保存され、別の端末からログインしても続きができる
- 登録時に「この端末にある牧場のデータを引き継ぐ」にチェックすると、ログインなしで遊んでいたデータをそのままアカウントに移せる
- パスワードはハッシュ化して保存。再発行機能はないので忘れないように
- 「ログインせずにこの端末だけで遊ぶ」も選べる（データはそのブラウザにだけ残る）

## 遊び方（オンライン機能）

- 厩舎画面の下メニュー「🌐 オンライン」から
- **馬券ランキング**：普段のレースで買った馬券の成績が自動で送られて、通算収支・最高払戻・対戦勝利で順位が出る
- **対戦**：ルームを作ってコードを友だちに伝える → 全員が出走させる馬を選ぶ → ホストが芝/ダート・距離・相手の強さを選んで開始
  - 45秒の馬券購入時間のあと、全員が同じレースを観戦する（全員が「待機」を押すと早く始まる）
  - プレイヤーの中で一番先にゴールした人の勝ち。賞金は出ないが、対戦勝利数がランキングに載る
